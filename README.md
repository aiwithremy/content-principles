# Content Principles

A Claude skill that teaches AI how to think about short-form content, instead of filling in a template.

Most content skills hand Claude a template: bold claim, numbered list, "follow for more". Claude follows it perfectly, and every post comes out sounding the same as everyone else's. This one has no template. It teaches Claude how your viewer's mind works (curiosity loops, specificity, line one selling line two), so it reasons about every video from scratch.

Made by [Remy Gaskell](https://www.instagram.com/aiwithremy) from 500+ hours studying the best short-form creators.

## Install

**The easy way:** paste this repo's link into Claude Code (or any AI agent that can install skills) and say:

> Install this skill for me: https://github.com/aiwithremy/content-principles

**Claude Code, by hand:** copy the `content-principles` folder into `~/.claude/skills/`.

**Claude.ai or the Claude app:** download this repo as a ZIP (green **Code** button, then **Download ZIP**), then go to Settings, then Capabilities, and upload it as a skill.

**ChatGPT:** copy the text of [`content-principles/SKILL.md`](content-principles/SKILL.md) into a custom GPT or a Project's instructions.

## Use it

Script like normal ("write me a reel about X", "give me 10 hooks for this"), or paste in something you've already written and ask Claude to audit it with the content principles skill.
